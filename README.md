Queen Black Dragon Helper!

Queen Black Dragon Helper does not provide early or predictive notifications for her Fire Walls or Extremely Hot Breath ability. As shown in the screenshots above, the UI displays an alert for these mechanics only when the corresponding message appears in your chat box, and the alert remains visible for only a short time.

The UI currently includes:

Displays the current phase

Shows when a Dragonkin Artefact is ready to be interacted with to begin the next phase, and displays it as activated during the current phase

Displays QBD's current form

When QBD enters her Crystal or Hardened Carapace form, the UI displays the form and her current weakness using colors that match the corresponding chat notification

Displays how many Tortured Souls are currently active

Displays when you are in the Time Stop portion of the fight

Displays brief alerts for Fire Wall and Extremely Hot Breath when their respective chat messages appear

Has an option to change the color of the text within the UI
The overlay can be moved and configured through the plugin settings, including display options, compact mode, color coding, individual information rows, and mechanic alert duration.
